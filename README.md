# The Printer Finally Answers

"Error 0x4A: I did not jam. I read page 2 of your report and refused on principle."

Two clauses, reversal in the second, one concrete object (page 2 of the
report) — the winning pattern from the autopsy of past make.fun text
competitions. The printer denies the jam, then reveals it read the report
and refused on principle: a machine with editorial standards, in flat
bureaucratic deadpan.

Fresh lane: of 266 entries in the field, 12+ are the same joke — "counted
41,208 sheets, zero thank-yous, jam on purpose / search-history threat".
The judge brief's criteria 2 and 5 punish exactly that (complaint with a
punchline bolted on; recycled paper jam line). This line never counts a
sheet, never mentions thank-yous, tray 2, or search history.
